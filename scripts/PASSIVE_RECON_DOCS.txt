
================================================================================
VAMPSECURE INTELLIGENCE - PASSIVE-RECON (OTX INTEL)
================================================================================

DESCRIPCIÓN:
Herramienta de inteligencia de amenazas (OSINT) que consulta la base de datos 
de AlienVault OTX para identificar indicadores de compromiso (IoC) relacionados 
con direcciones IP y dominios sospechosos.

CARACTERÍSTICAS:
- Integración nativa con API de AlienVault OTX.
- Extracción de etiquetas de malware y reputación.
- Detección de amenazas históricas y activas.

USO:
python3 scripts/passive_recon/passive_recon.py --target [IP_O_DOMINIO]

PRUEBA DE CONCEPTO (PoC):
1. Asegurar que la API Key esté en ./scripts/passive_recon/.env
2. Ejecutar análisis de IP sospechosa:
   docker exec -it vamp_python_lab python scripts/passive_recon/passive_recon.py --target 8.8.8.8

RESULTADO ESPERADO:
El script devolverá un informe detallado con las amenazas asociadas al objetivo 
si existen registros en la inteligencia global de OTX.
